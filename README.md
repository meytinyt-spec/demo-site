# Демо-Плёнка

Учебный одностраничный лендинг вымышленной мастерской по оклейке автомобилей плёнкой.
Бренд, цены, телефон и контакты условные.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Весь сайт: разметка и стили в одном файле, без сборки и зависимостей |
| `favicon.svg` | Иконка вкладки браузера |
| `og-image.png` | Картинка превью ссылки в Telegram, WhatsApp и соцсетях (1200×630) |
| `robots.txt` | Запрет индексации поисковиками |

## Как посмотреть локально

Откройте `index.html` в браузере — двойным щелчком или перетащив файл в окно.

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу
   `https://meytinyt-spec.github.io/demo-site/`.

Если сайт публикуется по другому адресу, замените URL в тегах `og:url` и `og:image`
в `index.html`, иначе превью ссылки не подтянет картинку.

## Демо-режим

- Сайт закрыт от поисковиков: `<meta name="robots" content="noindex, nofollow">` и `robots.txt`.
- Контакты-заглушки: ссылка `https://t.me/` и номер `+7 000 000-00-00`.
  Чтобы сайт стал «боевым», замените их на настоящие (поиск по `t.me/` и `70000000000`)
  и уберите блок `.disclaimer` в подвале и строку noindex.
