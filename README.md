# Canopy

Демо-версия сайта маркетингового агентства полного цикла для малого бизнеса.
Цель сайта — заявка на бесплатный разбор маркетинга.

Сайт: https://meytinyt-spec.github.io/demo-site/

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница: разметка и стили |
| `app.js` | Скрипт: плавающая кнопка на телефоне и форма заявки |
| `soglasie.html` | Шаблон согласия на обработку персональных данных (отдельный документ, 152-ФЗ) |

| `doc.css` | Общие стили трёх страниц-документов |
| `404.html` | Страница «не найдено» |
| `fonts/` | Шрифты Manrope и Unbounded (кириллица и латиница), лежат на сайте |

| `og-image.png` | Картинка превью ссылки в мессенджерах (1200×630) |

## Стиль

- Шрифты: заголовки Unbounded, текст Manrope. Файлы лежат в `fonts/`, к Google сайт не обращается.
- Цвета: тёплый светлый фон `#f6f4ef`, тёмный `#14211b`, зелёный `#1f6b46`,
  охра `#8f6418` (только номера и итоговые цифры).
- Скругления 4 px, без теней, иконок, градиентов и эффектов при наведении,
  кроме смены цвета.
- Все цвета заданы переменными в начале `<style>` в `index.html`.
- Главное доказательство на странице: образец еженедельного отчёта. Цифры в нём
  условные и подписаны как образец.

## Форма заявки

Сейчас форма работает в демо-режиме: проверяет поля, отсеивает простых ботов
(скрытое поле и проверка времени) и показывает «Спасибо», но никуда не отправляет данные.
Отправка — функция `sendLead()` в `app.js`. Схема подключения описана в `CHECKLIST.md`.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
Если адрес сайта поменяется, замените URL в тегах `og:url` и `og:image` в `index.html`.
