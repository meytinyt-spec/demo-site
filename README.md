# Canopy

Демо-версия сайта маркетингового агентства полного цикла для малого бизнеса.
Цель сайта — заявка на бесплатный разбор маркетинга.

Сайт: https://meytinyt-spec.github.io/demo-site/

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Весь сайт: разметка, стили и скрипт формы в одном файле, без сборки |
| `privacy.html` | Шаблон политики конфиденциальности (152-ФЗ) — заполнить поля в квадратных скобках |
| `favicon.svg` | Иконка вкладки (логотип: три растущих столбика с листом) |
| `og-image.png` | Картинка превью ссылки в Telegram, WhatsApp и соцсетях (1200×630) |

## Стиль

- Шрифт — Manrope (Google Fonts).
- Цвета: белый фон, тёмный `#0e1a14`, зелёный `#1f7a4c`, бледно-зелёный `#cfe3d7`,
  лаймовый акцент `#c6f36b`, светлый фон секций `#f3f6f4`.
- Все цвета заданы переменными в начале `<style>` в `index.html`.

## Форма заявки

Сейчас форма работает в демо-режиме: проверяет поля и показывает «Спасибо»,
но никуда не отправляет данные. Отправка — функция `sendLead()` в скрипте внизу
`index.html`; следующим шагом её подключим к Telegram.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
Если адрес сайта поменяется, замените URL в тегах `og:url` и `og:image` в `index.html`.

## Перед настоящим запуском

- Подключить отправку заявок в Telegram.
- Заполнить реквизиты в `privacy.html` и показать текст юристу.
- Убрать строку `<meta name="robots" content="noindex, nofollow">` из `index.html` и `privacy.html`.
- Убрать демо-плашку в подвале, подпись «Демо-режим» под кнопкой формы
  и заменить пример отчёта на реальные цифры.
