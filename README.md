# Canopy

Демо-версия сайта маркетингового агентства полного цикла для малого бизнеса.
Цель сайта — заявка на бесплатный разбор маркетинга.

Сайт: https://meytinyt-spec.github.io/demo-site/

Сайт статический: без сборки, библиотек и внешних сервисов. Чтобы посмотреть его
локально, достаточно открыть `index.html` в браузере.

## Структура

```
index.html              главная страница
404.html                страница «не найдено»
legal/
  consent.html          согласие на обработку персональных данных (отдельный документ, 152-ФЗ)
  privacy.html          политика конфиденциальности
  terms.html            пользовательское соглашение
assets/
  css/
    base.css            общее для всех страниц: цвета, шрифты, кнопки, шапка, подвал
    home.css            главная страница, по разделам в порядке их появления
    legal.css           документы и страница 404
  js/
    lead-form.js        форма заявки: проверка, защита от ботов, отправка
    mobile-cta.js       плавающая кнопка «Записаться» на телефоне
  fonts/                Manrope и Unbounded (кириллица и латиница) и их подключение
  img/                  логотип, иконки, картинка превью ссылки
_config.yml             что GitHub Pages не должен публиковать
README.md               это описание (не публикуется)
CHECKLIST.md            чек-лист запуска (не публикуется)
```

## Где что менять

| Задача | Где |
|---|---|
| Цвета, шрифты, скругления | переменные в начале `assets/css/base.css` |
| Тексты главной | `index.html`, разделы отмечены комментариями |
| Внешний вид раздела главной | `assets/css/home.css`, раздел с тем же названием |
| Включить отправку заявок | `LEAD_ENDPOINT` в начале `assets/js/lead-form.js` |
| Реквизиты и контакты | подвал и блок «Если удобнее написать самим» в `index.html`, поля в квадратных скобках в `legal/` |
| Логотип | `assets/img/logo.svg` (он же иконка вкладки) |

## Правила кода

- Никаких стилей и скриптов внутри HTML: только файлы из `assets/`. Заголовок
  безопасности (Content-Security-Policy) на каждой странице запрещает встроенный код.
- Все цвета берутся из переменных `base.css`, новых цветов прямо в правилах не пишем.
- Правила для телефона лежат рядом с разделом, к которому относятся.
- Комментарии на русском.

## Стиль

- Шрифты: заголовки Unbounded, текст Manrope.
- Цвета: тёплый светлый фон `#f6f4ef`, тёмный `#14211b`, зелёный `#1f6b46`,
  охра `#8f6418` (только номера и итоговые цифры).
- Скругления 4 px, без теней, иконок, градиентов и эффектов при наведении,
  кроме смены цвета.
- Главное доказательство на странице: образец еженедельного отчёта. Цифры в нём
  условные и подписаны как образец.

## Форма заявки

Пока `LEAD_ENDPOINT` в `assets/js/lead-form.js` пустой, форма работает в демо-режиме:
- проверяет поля;
- отсеивает простых ботов: скрытое поле и проверка времени заполнения;
- показывает «Спасибо», но никуда не отправляет данные.

Подписи «Демо-режим» отмечены атрибутом `data-demo-only` и исчезают сами, когда
адрес сервера заполнен. Схема подключения описана в `CHECKLIST.md`.
